# 🤖 Autonomous Car Diagnosis Robot & Predictive Maintenance System

Live portfolio project featuring multi-factor OBD-II diagnostic priority scoring (30% Anomaly Deviation, 25% Preventive Savings, 25% Robot Sensor Confidence, 20% Historical Frequency), interactive subsystem filtering, and visual telemetry analytics.

## 🚀 Two Ways to Host Permanently
1. **GitHub Pages (Instant, Never Sleeps):** Upload `index.html` to your GitHub repo and enable **Settings -> Pages**.
2. **Streamlit Community Cloud:** Connect this GitHub repository at `share.streamlit.io` and select `app.py`.
